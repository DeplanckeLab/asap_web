ASAP: enabling collaborative analysis and annotation of large omics datasets in a reproducible way

ASAP is a web platform for reproducible single cell and bulk transcriptomics analysis. Recent work strengthens scalability, improved user experience, and alignment with community metadata standards, while foregrounding how users actually see, explore, and annotate their data.

Engineering is organized across the Ruby on Rails 8.0 web stack (asap_web), dedicated bioinformatics containers (asap_run), and the main ASAP GitHub repository for feedback and discussion. Jobs are now scheduled through SLURM and site search has been migrated to Elasticsearch.

In March 2026 we released a new interface around a new interactive embedding visualization: responsive maps in reduced dimensional space, with flexible coloring by sample metadata or gene expression and smooth navigation between views so that structure in large atlases can be inspected without heavy tutorial overhead. The layout is deliberately intuitive for day to day analysis, exploration and collaborative interpretation, with support for annotations in the context of analysis results, so project members can work together on the same dataset, converge on labels (e.g. cell types), and keep a shared record of biological decisions as the analysis evolves.

ASAP is an SIB resource and a core participant in scFAIR, promoting FAIR practices for single cell data and metadata. With partners including Bgee, CELLxGENE, and the EBI Single Cell Expression Atlas we align on metadata conventions; cell lines use Cellosaurus nomenclature, and an online validator against the scFAIR schema is being integrated on the portal. A generic pipeline framework already runs single cell and bulk RNA-seq and is designed to extend toward spatial transcriptomics, metabolomics, and proteomics, supporting a scalable route from raw omics data to shared, visually grounded discovery. Projects can be made public so that the full analysis context and annotation work are visible to the wider community, enabling feedback and discussion. Once a project is public, community members can contribute additional annotations, enriching the resource beyond the original team's work.
