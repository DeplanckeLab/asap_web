## New version of ASAP with Rails 8 + TailwindCSS + Importmaps

WARNING: This is a work in progress. It's not ready for production.

### Steps to install

1. Clone the repository
2. Get database dump
3. Edit environment variables in .env file (not committed)
4. Start docker compose

Operational notes with real host paths, credentials, and Fail2ban layouts are kept out of Git: use `docs/*.md.example`, `slurm/*.example`, `private/` (gitignored snapshot on this machine only), or a private ops repository.
